# dual-boot-windows-et-linux-
Projet : Dual-Boot Windows 11 & Debian GNU/Linux

Ce dépôt documente le processus complet d'installation et de configuration d'un environnement en double amorçage (dual-boot) associant Windows 11 et Debian.

🎯 Objectif du projet :
Réalisé dans le cadre d'un projet personnel d'auto-apprentissage, ce projet vise à mettre en place un environnement Linux natif et performant pour réaliser de futurs projets (développement, administration système, conteneurisation), tout en conservant un système Windows 11 fonctionnel pour les usages quotidiens.

📋 Étapes couvertes :

Préparation et sécurisation de l'environnement Windows 11 (partitionnement des disque dur ).

Création de la clé USB d'amorçage via Rufus (UEFI / GPT).

Déploiement guidé de Debian 13 et configuration du chargeur d'amorçage GRUB.
